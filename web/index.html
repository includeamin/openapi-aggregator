openapi-aggregator

Merge OpenAPI specs from many services into one

Add specs, write an openapi-aggregator.yaml config, and see the merged result. Everything runs in your browser with the same engine as the CLI, so nothing is uploaded.

Install the CLI How merging works

Files

    No files yet. Add one, upload a spec, or import it from a URL.

    Settings

    Added in front of every fetched URL. Stored only in this browser.

    Variables

    Values for ${VAR} in source URLs and headers. Stored only in this browser and never put in share links.
